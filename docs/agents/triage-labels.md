# Triage Labels

The engineering skills use five canonical triage roles. This file maps those roles to this repository’s GitHub labels.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a canonical role, use its corresponding GitHub label.

The repository currently has GitHub’s standard default labels. Of these five labels, only `wontfix` already exists; the others use new, non-conflicting names.
